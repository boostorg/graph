= `make_maximal_planar`

Adds edges to a biconnected planar graph to make it maximal planar.

*Complexity:* _O(n + m)_ +
*Defined in:* `<boost/graph/make_maximal_planar.hpp>`

[#passing-the-visitor]
=== Passing the visitor

* Pass `std::ref(vis)` when you need the visitor's state after the call, for example an `edge_index_update_visitor` shared across several calls.
* Pass a temporary, or omit the visitor, when you do not need its state.
* Do not pass a named, non-const visitor bare. It currently selects the <<deprecated-visitor-reference,deprecated overload>> and emits a deprecation warning. From Boost 1.95 the same call compiles silently but works on a copy, so your visitor is left unchanged. Treat the warning as a bug.

[source,cpp]
----
make_maximal_planar(g, embedding, get(vertex_index, g), get(edge_index, g), std::ref(edge_updater));
make_maximal_planar(g, embedding, get(vertex_index, g), get(edge_index, g), my_visitor());
----

'''

[#deprecated-visitor-reference]
=== Visitor by non-const reference (deprecated)

[WARNING]
====
Deprecated: this overload takes the visitor by non-const reference, which rejects temporaries and differs from the other BGL algorithms, which take visitors by value. It is selected when a named, non-const visitor is passed without `std::ref`. Removal planned for Boost 1.95. See <<passing-the-visitor,Passing the visitor>> to migrate.
====

== Description

A xref:algorithms/planar/planar_graphs.adoc[planar graph] _G_ is _maximal planar_ if no additional edges (except parallel edges and self-loops) can be added to _G_ without creating a non-planar graph. By xref:algorithms/planar/planar_graphs.adoc#EulersFormula[Euler's formula], a maximal planar graph on _n_ vertices (_n > 2_) always has _3n - 6_ edges and _2n - 4_ faces. The input graph to `make_maximal_planar` must be a xref:algorithms/planar/make_biconnected_planar.adoc[biconnected] planar graph with at least 3 vertices.

The default behavior of `make_maximal_planar` is to modify the graph `g` by calling `add_edge(u,v,g)` for every pair of vertices _(u,v)_ where an edge needs to be added to make `g` maximal planar. This behavior can be overridden by providing a visitor as the `AddEdgeVisitor` parameter. The only requirement for an `AddEdgeVisitor` is that it define a member function with the following signature:

[source,cpp]
----
template<typename Graph, typename Vertex>
void visit_vertex_pair(Vertex u, Vertex v, Graph& g);
----

This event point can also be used as a hook to update the underlying edge index map automatically as edges are added. See the documentation for the xref:visitors/AddEdgeVisitor.adoc[AddEdgeVisitor] concept for more information.

See also link:../example/make_maximal_planar.cpp[examples/make_maximal_planar.cpp].

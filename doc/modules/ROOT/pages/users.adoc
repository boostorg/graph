= Who Uses the Boost Graph Library

The BGL sits underneath a fair amount of widely used software.
Below is a selection of projects that depend on it, what they are,
and what the graph part actually does for them.

If you use the BGL and want to be listed here,
open a https://github.com/boostorg/graph/discussions[discussion] or send mail to
the Boost users mailing list.

== Projects

Entries were checked against each project's source code in September 2026.
